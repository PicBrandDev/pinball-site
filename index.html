Regenerar modelos e imagens

Os arquivos STEP em cad/ são a fonte. Modelos GLB, STL, tabelas e imagens são derivados. Requer Node.js 20 ou mais recente.

npm install
npm run convert        # cad/**/*.step → docs/models/*.glb, cad/stl/*.stl, manifest.json
npm run serve          # este site em http://localhost:5173
bash tools/render.sh   # com o servidor no ar: recria docs/img/*.png
npm run publish-site   # envia docs/ para o site público

Os arquivos-fonte ficam no repositório privado PicBrandDev/pinball; os links STEP e STL desta página exigem acesso a ele.

Pontos em aberto

  • Material e processo de cada peça de fabricação, e espessura real das chapas de madeira.
  • Corpos sem nome descritivo na montagem: 1.7.5 (barra de 258,5 × 15 × 34,4 mm junto à canaleta de coleta) e SOLID (11,3 × 12 × 15,7 mm, perto da ponte do tiro).
  • Superfícies sem volume (corpo_19, corpo_30, corpo_32) parecem resíduos de construção exportados junto.
  • BORDA_DIRETA.step tem 3 corpos, enquanto as outras peças têm 1.
  • Esquema elétrico, controlador e firmware não fazem parte do projeto CAD.
